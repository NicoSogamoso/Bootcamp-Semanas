# 🏛️ Semana 02 — Club Social (Express CRUD)

API REST con Express 5 + TypeScript. Store en memoria.

## Endpoints

| Método | Ruta | Status |
|--------|------|--------|
| GET | `/api/v1/members` | 200 |
| GET | `/api/v1/members/:id` | 200 / 404 |
| POST | `/api/v1/members` | 201 |
| PUT | `/api/v1/members/:id` | 200 / 404 |
| DELETE | `/api/v1/members/:id` | 204 / 404 |

```bash
cd 3-proyecto/starter && pnpm install && pnpm dev
```
