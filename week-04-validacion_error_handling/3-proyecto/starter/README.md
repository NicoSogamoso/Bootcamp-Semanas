# 🏛️ Semana 04 — Club Social (Zod + AppError + Winston)

Validación Zod, errores estructurados y logging profesional.

## Validaciones
- `fullName`: min 2 chars
- `membershipType`: regular | vip | honorario
- `monthlyFee`: >= 0
- `joinedAt`: YYYY-MM-DD
- `:id`: número entero positivo
